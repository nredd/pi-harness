- **Lifecycle events carry the agent's `handle` and `name` ([#444](https://github.com/nredd/pi-harness/issues/444)).** `subagents:created`, `started`, `completed`, `failed` and `compacted` add `handle` (`explore-2`), `name` (the handle from the spawner's `name`, `auth-audit` or a numbered `auth-audit-2`), `nameBase` (that name unnumbered, `auth-audit`) and, for an evicted agent reopened under a new id, `previousId`, each omitted when absent, plus `spawnSeq` (creation order, before any queueing) and on `completed`/`failed` `settleSeq` from the same counter, so a listener can match an agent by what the parent typed. pi-todo uses them to show a todo owner's live state.
