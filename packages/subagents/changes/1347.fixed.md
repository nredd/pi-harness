- **A crashed subagent writer's claim no longer refuses forever when an unrelated process reuses its pid ([#1347](https://github.com/nredd/pi-harness/issues/1347)).** On Linux a `<transcript>.writer` claim now records its writer's start time (`/proc/<pid>/stat` field 22), and a claim whose pid is alive in the same PID namespace and boot but started at another time is taken over as stale. A claim without a start time (written by an earlier version), a start time that cannot be read, and every non-Linux host still count a live pid as the holder.
