- **An injected home no longer reads the ambient `~/.agents/skills` root ([#179](https://github.com/nredd/pi-harness/issues/179)).** `homeDir` now reaches Pi's resource loader and package manager, so with core `v1.3.0-nredd.10` or later the automatic user skills root follows the injected home; older SDKs still scan it and preloads filter the results. Probes through the real runner, mention clone, preload and child sessions assert zero ambient reads.
