- **BREAKING: Explore and Plan get only `read`, `grep`, `find` and `ls` ([#267](https://github.com/nredd/pi-harness/issues/267)).** They lose `bash` and every extension tool (`extensions: false`), so their read-only prompts are enforced by the tool surface instead of trusted. Plan no longer reaches `cargo_*`, `py_test` or other dev-tools. This is a tool restriction, not an OS or filesystem sandbox. To keep command work, delegate to a shell-capable type such as `general-purpose`, or override `Explore`/`Plan` by name in `.pi/agents/` with explicit `tools:` and `extensions:`.
