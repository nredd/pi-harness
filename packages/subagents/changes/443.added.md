- **`stop_subagent` and a stop-all chord ([#443](https://github.com/nredd/pi-harness/issues/443), [#454](https://github.com/nredd/pi-harness/issues/454)).** The model could not stop an agent it started: a steer of "STOP NOW" was read after the child's current tool call and the child ran more. `stop_subagent` takes an id, handle, name or `SubagentWorkflow` Task ID and goes through the existing stop, so the run starts no further tool call, ends `stopped`, keeps its worktree branch, and sends one notice saying the parent stopped it. An unknown or finished id lists what is running; nested and workflow children stay unreachable from the top level, and children get the tool only with `allowed_subagents`. `ctrl+shift+k` twice within 3s, or `/agents -> Stop all running`, stops every running agent and workflow. `steer_subagent` now refuses any `stopped` agent with neutral wording.
