- **A background agent no longer dies with "This extension ctx is stale" after the parent reloads or replaces its session ([#145](https://github.com/nredd/pi-harness/issues/145)).** Two causes. The manager's usage and compaction observers close over the spawning activation's `pi`, and pi records a throw from a session listener as the child's turn failure, so the first message after a reload ended a detached child with an empty error turn; observers are now isolated from the run. Core #581 subsequently moved virtual routing to the requesting session's context. Other stale-context failures now terminate without blind retry under #779, retaining their diagnostic and bounded activity summary rather than assuming a reload.
