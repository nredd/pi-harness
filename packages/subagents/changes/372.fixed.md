- **An evicted agent's result and name outlive the record for the session ([#372](https://github.com/nredd/pi-harness/issues/372)).** The 10 and 60 minute record windows are unchanged, but eviction now keeps the result text (a failed run's error too), capped at 32000 characters with a marker naming the transcript, so `get_subagent_result` after eviction returns the result instead of only a transcript path. The 100-tombstone, 500-note and 500-reopen-link caps are gone: all live for the session and end at `/new` / `/resume`. A saved session's result text comes back on `/resume` and restart, the retained copy never pins the full original string, and a 5000-tombstone per-session safety bound (oldest first) guards a runaway session. The `subagent-reaped` notice says `get_subagent_result` still returns the capped result only when result or error text was kept, and `resume` of an agent the bound dropped names its session file to reopen.
