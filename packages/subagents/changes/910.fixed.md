- **Workflow `meta` evaluation tolerates a loaded host ([#910](https://github.com/nredd/pi-harness/issues/910)).** The wall-clock bound on evaluating the `meta` literal rises from 100ms to 1s, so scheduler jitter no longer fails a valid workflow with "did not finish evaluating". The runaway guard still holds: a non-terminating `meta` is cut off at the bound.
