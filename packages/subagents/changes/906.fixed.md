- **A resumed workflow child is relabeled per answered message ([#906](https://github.com/nredd/pi-harness/issues/906)).** `agent(..., { resume })` on a virtual model reported the child's effective model and `thinking` only at settle, so the card showed no level while the resume ran. It now reports from the record before the resume starts and after each answered message, with unchanged reports skipped, so a non-reasoning physical model reads `thinking: off (asked high)` while running.
