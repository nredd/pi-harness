- **Workflows stop cleanly at session end ([#1257](https://github.com/nredd/pi-harness/issues/1257)).** Ending a session waits for each stopped workflow's worker thread and completion handling instead of letting the run settle afterwards and arm a notice timer on the closed queue. On `/new`, `/resume`, `/fork` or `/reload` its `Stopped` notice is now kept for the session you left; on quit it is dropped.
