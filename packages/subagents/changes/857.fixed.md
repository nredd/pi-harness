- **FleetView overflow indicators are left-aligned and no blank rows pad the block ([#857](https://github.com/nredd/pi-harness/issues/857)).** `↑ N more` / `↓ N more` were right-aligned behind a line of spaces as wide as the terminal, so they read as blank rows, and the unused indicator slot at a scroll edge was a real blank row. They now sit dim in the bullet column with a two-space indent and truncate on narrow terminals; an edge's free slot holds one more agent row (top 4 rows + `↓`, middle `↑` + 3 rows + `↓`, bottom `↑` + 4 rows), so the block stays five lines.
