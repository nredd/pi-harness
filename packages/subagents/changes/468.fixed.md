- **`subagents:rpc:steer` refuses a pre-Plan agent while planning ([#468](https://github.com/nredd/pi-harness/issues/468)).** `steer_subagent` already refused to steer a running or queued agent with no Plan restrictions, but another extension's tool could do the same over the RPC channel and drive it into edits. The channel now answers with the same refusal. The README's Plan mode section also says how a malformed or version-skewed Plan answer shows up, and that the handshake is hardening, not a sandbox.
