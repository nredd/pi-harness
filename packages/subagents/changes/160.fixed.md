- **Package tests accept explicit home directories on both engines ([#171](https://github.com/nredd/pi-harness/pull/171), refs [#160](https://github.com/nredd/pi-harness/issues/160)).** Bun caches `os.homedir()`, so changing `HOME` in a test could read the real user's agents, skills or settings. User-path discovery and child sessions now accept injected homes; normal runtime defaults and collision precedence are unchanged. See `docs/home-injection.md` for the boundary audit and regressions.
