- **Worktree cleanup keeps edits hidden by index bits and ignored clones under mis-decoded paths ([#596](https://github.com/nredd/pi-harness/issues/596)).** An edit to a file marked `assume-unchanged` or `skip-worktree` left `status` and git's removal check clean, so the edit was deleted and cleanup reported no changes; those bits are now cleared before the check (a skip-worktree file absent from disk is left alone), in nested repositories too. A regular file with a mode change staged in the index (vs HEAD, or on a newly added file) that the file on disk no longer matches (`update-index --chmod`) now keeps the worktree with an error naming the paths, before `add -A` could drop the mode. An ignored nested clone under a non-ASCII path was skipped and deleted; path listings are now read quoted and decoded exactly, and a path that cannot be decoded keeps the worktree with an error (core fix: nredd/pi#22).
