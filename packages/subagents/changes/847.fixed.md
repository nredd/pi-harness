- **A router-backed row shows the level the request ran at** ([#847](https://github.com/nredd/pi-harness/issues/847)). Once a response lands, the row takes the physical model's effective `thinking` from the answered message instead of keeping the session level, so a non-reasoning physical model reads `think:off (asked high)` rather than `think:high`. The request is still kept as `(asked X)`.
