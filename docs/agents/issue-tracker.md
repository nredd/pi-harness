# Issue tracker

Use GitHub issues and pull requests in `nredd/pi-harness`.

- Read an issue with `gh issue view <number> --repo nredd/pi-harness --comments`.
- Read a PR with `gh pr view <number> --repo nredd/pi-harness` and `gh pr diff <number> --repo nredd/pi-harness`.
- Use `docs/migration-plan.md` plus the PR's scoped requirements as the migration review spec.
- Follow `AGENTS.md` for the mandatory two-axis review and evidence requirements.

Do not switch another developer's worktree to inspect a PR.
